  AWS のシークレットキーが、JSON や Python の辞書の書き方ではマスクされない。
  式はキー名の直後に `=` か `:` を求めるので、キー名を閉じる引用符が間に入ると一致しない
  (`{"aws_secret_access_key": "<値>"}`)。`redact()` はキーと値を別々にマスクするので、
  辞書 `{"aws_secret_access_key": <値>}` の値も残る。モデルが要約に写せば、
  Slack の投稿文を作る `_free_text()` も通り抜ける。
  §15 の「形の決まっていない秘密」ではなく、§18 A5 で対応したと書いた形の抜け。
  → **検証: 確認済み (再現)**。引用符つきの 2 つの書き方と、辞書を `redact()` に渡す形で値が残った。
  `aws_secret_access_key=<値>` の形はマスクされる。`_free_text()` の出力にも値が残った。
  → 窓口の見立て: 漏れるには、記録にこの形でキーが入り、モデルが要約に写す、の両方が要る。
  フラグは既定でオフ。重大度は P2 寄りと見るが、フラグをオンにする前には直す必要がある。
  → 直し方の案: 構造化データでは、秘密のキー名に対応する値をマスクする。
  文字列の式は、引用符つきのキー名にも一致させる。

- **② P2 / 本番のイメージに入る / 既知の制限に書かれているが、実態より控えめ**
  `src/agent/diagnosis/tools.py:510`、`src/agent/diagnosis/frames.py:68`
  連鎖した例外で、内側と外側が同じ型だと、内側の場所が外側の例外の受け渡しに使われる。
  A3 の確かめは「最初のブロックを終える行の型の名前が、記録された `error_type` と同じか」で、
  型が同じ連鎖は通る。§15「修正役に渡らない場合」は、連鎖した例外は渡らないと書いている。
  → **検証: 確認済み (再現)**。`error_type` が `ValueError`、内側も外側も `ValueError` の
  2 ブロックのトレース (`__cause__` と `__context__` の両方の区切り文) で、
  内側の `call_claude` のフレームを選ぶ提出が受理され、`fixer_eligible` が真になった。
  → 影響は、修正役に渡る場所が的外れになること。場所は実在するコードに限られる。
  → 直し方の案: 連鎖の区切り文を含むトレースは受け渡しの対象から外す。

- **③ P2 / 修正役だけ / 既知の制限に書かれていない**
  `src/fixer/gitio.py:425` (`_describe`)、`:276`、`src/fixer/runner.py:876`
  元のリポジトリの設定とフックの照合に、大きさ・深さ・時間の上限が無い。
  (a) `.git/hooks` の下に巨大な疎なファイルを置かれると、全体をハッシュする。検査の期限は効かない。
  (b) `.git/hooks` の下に深いディレクトリを作られると、再帰する `_describe()` が `RecursionError` を上げる。
  `repository_fingerprint()` が受けるのは `OSError` だけ、`_repository_was_changed()` が受けるのは
  `GitError` だけなので、`run_fix()` の終わりの照合から例外が漏れ、結果ファイルが書かれない。
  (c) `.git/info/attributes` は `read_bytes()` で全体を読んでから切っている。
  → **検証: 確認済み**。(a) 再現: 2GiB の疎なファイルを最後まで読んだ (この環境で約 1 秒。大きさに比例する)。
  (b) 部分的に再現: 深さ 300 のディレクトリで、再帰の上限を 200 に下げると、`RecursionError` が
  `repository_fingerprint()` と `_repository_was_changed()` の両方から漏れた。既定の上限 (1000) では、
  深さ約 1000 が要る。macOS (パスの上限 1024 バイト) では先に `OSError` になり `GitError` として受けられる。
  Linux (パスの上限 4096 バイト) では届く計算だが、実機では未確認。(c) コードを読んで確認。
  → 直し方の案: 照合に、ファイルごと・合計・件数・深さ・時間の上限を付け、超えたら「変わった」とみなす。
  `_describe` を再帰でなくする。属性のファイルは上限つきで読む。終わりの照合の失敗も結果に残す。
